# 🧠 How I Approach Cybersecurity

</div>

<p align="center">
<strong>Understand → Break → Analyze → Defend → Improve</strong>
</p>

I like looking at security problems from both sides.

I try to understand how a system works, where its attack surface
exists, how it could potentially be abused, and how that knowledge
can be turned into a practical defensive or investigative solution.

> **Understanding the attacker helps build better defenses.**
